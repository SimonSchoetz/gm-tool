# Sub-feature 7: Add tab: Entities / Other switch, random combatant and event forms

The Add tab starts with an Entities / Other switch. Entities shows the existing entity list unchanged; Other shows an Event / Random Combatant switch and the two forms. The three panels stay mounted and hidden when not shown, so drafts survive every switch and a switch to the Actions or Log tab. The quantity logic of the entity rows moves into one hook and one input component that the random combatant form shares.
