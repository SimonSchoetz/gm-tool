# Fonts research and findings

Rather than searching for a single perfect font, we build a two-family system:
| Purpose | Typeface |
| --- | --- |
| UI | [IBM Plex Sans](https://fonts.google.com/specimen/IBM+Plex+Sans) |
| Code, IDs, coordinates, metadata, version numbers, technical labels | [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono) |

This mirrors the visual language of engineering documentation, CAD software, and technical manuals—the same influences visible in your blueprint references while preserving the reading comfort expected from a productivity application.
